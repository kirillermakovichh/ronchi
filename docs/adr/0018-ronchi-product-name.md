# Ronchi product name and positioning

The product is named **Ronchi**, with the primary tagline **“Make hidden failures visible.”** and descriptor **“An open-source, local-first reliability lab for blockchain applications.”** The name connects the product to the Ronchi optical test: a controlled probe makes otherwise hidden deviations observable, while interpretation still depends on evidence and context. Product copy, CLI commands, workspace paths, SDK naming, and visual identity use Ronchi; previous working names are retired.
